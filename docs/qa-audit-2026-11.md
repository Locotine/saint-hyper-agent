# Saint Full-Repo QA Audit & Bug Remediation Report (2026-11)

## 1. Tóm tắt điều hành (TL;DR)

Cuộc kiểm toán QA toàn diện được thực hiện song song trên 5 phân hệ (`apps/web`, `apps/server`, `apps/desktop-rust`, `packages/shared`, `packages/contracts`) theo 6 trọng tâm:

1. Streaming, reconnect, cancellation, recovery và đồng bộ state giữa server ↔ web/desktop.
2. Remote SSH & đa provider (Codex, Claude, Cursor, OMP, Antigravity, v.v.).
3. Composer & Input (IME tiếng Việt/CJK, paste, `@` mention/`@local`, `/fast`, phím tắt).
4. Transcript & Scroll (end-follow, detach, layout shift/clamp).
5. Editor, Split pane, Terminal, Settings, persistence & Beta/Stable gates + chuẩn UI (`AGENTS.md`).
6. Tương thích chéo 3 hệ điều hành (Windows, macOS, Linux Ubuntu/Debian).
