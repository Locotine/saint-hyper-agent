# Saint Full-Repo QA Audit & Bug Remediation Report (2026-11)

## 1. Tóm tắt điều hành (TL;DR)

Cuộc kiểm toán QA toàn diện được thực hiện song song trên 5 phân hệ (`apps/web`, `apps/server`, `apps/desktop-rust`, `packages/shared`, `packages/contracts`) theo 6 trọng tâm:

1. Streaming, reconnect, cancellation, recovery và đồng bộ state giữa server ↔ web/desktop.
2. Remote SSH & đa provider (Codex, Claude, Cursor, OMP, Antigravity, v.v.).
3. Composer & Input (IME tiếng Việt/CJK, paste, `@` mention/`@local`, `/fast`, phím tắt).
4. Transcript & Scroll (end-follow, detach, layout shift/clamp).
5. Editor, Split pane, Terminal, Settings, persistence & Beta/Stable gates + chuẩn UI (`AGENTS.md`).
6. Tương thích chéo 3 hệ điều hành (Windows, macOS, Linux Ubuntu/Debian).

## 3. Các hạng mục UI / Chrome / Flow đang giữ lại chờ phê duyệt (`AGENTS.md`)

Theo nguyên tắc bảo vệ UI trong `AGENTS.md` (_mọi thay đổi bố cục, style, chữ hiển thị, phím tắt mặc định, window chrome, menu bar và luồng tương tác người dùng đều cần xác nhận tường minh_), **10 lỗi đầy đủ** và **4 phần mở rộng UX/flow** dưới đây được ghi nhận riêng, **chưa thay đổi UI** trong nhánh `fix/bugs`:

### 3.1. 10 lỗi chờ duyệt hoàn toàn

1. **`B26` (Clipboard chứa cả file ảnh lẫn URL text):** Khi người dùng "Copy Image" từ trình duyệt và dán vào composer, ưu tiên **chỉ đính kèm ảnh** (đồng nhất với `ComposerBigPastePlugin`) hay **chỉ chèn link chip**?
2. **`B31` (`scroll-edge-fade` trên WebKitGTK / Firefox / Safari cũ):** Khi trình duyệt không hỗ trợ `animation-timeline: scroll()`, nên **tắt mask fade tĩnh** (`0px`/`0`) hay **dùng JS gắn attribute `data-can-scroll-up/down`** để fade theo vị trí cuộn thật?
3. **`B35` (Mặc định Custom Title Bar trên Linux `desktop-rust`):** Nên chọn mặc định Linux là **`false` (native OS titlebar)** (đồng bộ `packages/shared` & `apps/web` theo Rust) hay **`true` (custom titlebar)** (đổi Rust theo `packages/shared`)?
4. **`B36` (Window Chrome macOS & Translucency Hyprland/macOS):** Có bật `.title_bar_style(TitleBarStyle::Overlay).hidden_title(true)` + `.transparent(true)` trên macOS và `.transparent(true)` trên Hyprland để khớp với 78px gutter & theme translucent của `apps/web` không?
5. **`B37` (Blur radius trên macOS `apply_window_material`):** Sửa `apply_vibrancy` truyền `None` cho `corner_radius`, hay trả về `false` khi theme yêu cầu custom `blurRadius` để web hiển thị thông báo `desktopBlurUnavailable` đúng thực tế?
6. **`B39` (Native Application Menu & `menu_accelerators`):** Có dựng đầy đủ native Tauri `Menu` (App/Edit/View/Window + `terminal.new`, `sidebar.toggle`, `browser.toggle`) trên macOS/Win/Linux, hay bỏ qua menu native?
7. **`B40` (Phím tắt mặc định `composer.focus.toggle` trên Linux/Windows):** Đổi sang `Ctrl+L` hay `Ctrl+Shift+L` (với điều kiện `whenNotTerminalFocus && !isMac`)?
8. **`B41` (Clamp & fade bóng tin nhắn user dài):** Có chấp nhận điều chỉnh heuristic wrap hoặc tăng vùng fade đáy lên `>= 1.5 * lineHeightPx` để tránh cắt ngang chữ markdown trong khung hẹp không?
9. **`B43` (Copy "Host requirements" trong Settings → Remote hosts):** Duyệt cập nhật text hiển thị tại `RemoteHostsSettingsPanel.tsx:638-646` theo đúng `REMOTE.md:117` (bỏ `npm`/C++ compiler/Python, thay bằng `tar` và tùy chọn `tmux`)?
10. **`B46` (`saint://` Deep Link & plugin `global-shortcut`):** Desktop Rust có hỗ trợ deep link `saint://` (cài `single-instance` + `deep-link`) không, hay gỡ `MimeType=x-scheme-handler/saint;` khỏi `linux/saint.desktop` và gỡ `tauri-plugin-global-shortcut` chưa dùng?

### 3.2. 4 phần mở rộng UX/flow trên các bug đã vá phần lõi an toàn

1. **`B01` & `B24a` (Ảnh/PDF/HTML offline trên remote thread read-only):** Hiện đã ngăn crash và ngăn request vào local origin khi offline, đồng thời tự tải lại khi reconnect. Có muốn thiết kế thêm UI placeholder riêng (ví dụ: _"Connect host to view image"_) khi host đang offline không?
2. **`B07` (Remote multi-account, `customModels` & `hiddenProviders`):** Hiện đã chặn cold-fallback sang provider local-only (`cursor`, `antigravity`, ...) và chặn prefetch thừa trên remote. Cần quyết định nghiệp vụ:
   - Remote host có hỗ trợ chọn nhiều account (`providerInstances`) trả về từ remote `server.getConfig()` không, hay cố ý chỉ dùng instance mặc định của từng provider?
   - `customModels` và `hiddenProviders` trên remote host nên đọc từ cấu hình server remote (tách biệt hẳn local `settings.customModels`) đúng không?
3. **`B24b` (Auto-reconnect khi `Stop server` thất bại nhanh):** Hiện `hostReconnect` đã reset `everConnected` khi qua `"idle"`/`"stopping"`. Nếu `stop_server` chuyển thẳng sang `"error"` trước khi web kịp nhận frame `"stopping"`, có nên gắn thêm cờ `stopping` / suppressed error từ Rust để đảm bảo lệnh Stop thất bại không bao giờ tự kích hoạt reconnect không?
4. **`B32` (Đóng tab cuối cùng trong `EditorWorkspaceView`):** Hiện đóng tab đang `fileEdit` đã gọi `props.onCloseEdit()`.
