## 4. Known gaps to report

- Capability ceilings live in memory: after a server restart a flow node's thread falls back to the default capability set until the flow spawns its next thread (P4).
- A child created by `saint_create_threads` is narrowed when its credential is next verified, not at issue; the window is the child's first milliseconds (P4).

- Protected-path detection needs a git baseline: in a non-git project folder, or a repo without a first commit, gates still run but test edits are not flagged (P3).
- Autopilot currently behaves like auto_refix; switching agent/provider on failure lands with quota failover (P7).

- Edge `workspace: fresh` (a node in its own worktree) is not implemented yet: every node thread runs in the project folder (P2). Planned with the gate runner (P3).
- Node threads use `creationSource: "flow_node"`; check the sidebar and Kanban show or hide them as intended (P10–P12).

- Windows has no OS sandbox: L2+ autonomy and auto-approve stay locked there.
- macOS sandbox tests cannot run on the Linux dev machine; they run on macOS CI or a Mac.
- Provider resume after hibernation must be confirmed per provider; providers that cannot resume are excluded.
